PDPA Malaysia 2010

Architectural compliance
§4 Personal Data — General Principle
No personal identifiers stored. Edge gateway emits only {room_id, headcount, confidence}. See backend/models.py::SensorEvent — there is no person FK, no badge ID, no facial vector.
§5 Notice & Choice
No notice required because no personal data is collected. ToF range frames never leave the edge (slide 6 patent: Identity-Presence Decoupling).
§9 Retention
Sensor events are aggregate counts only. Retention policy configurable; default audit window 30 days for compliance evidence.

ISO/IEC 27001:2022 — Information Security

Architectural compliance
A.5.15 Access Control
API key gating on write paths (POST/DELETE /override, POST /rooms/.../budget, POST /nudge/test). Read paths are unauthenticated by design (compliance dashboards are observe-only).
A.8.16 Monitoring Activities
Every power decision is logged with full reason in PowerDecision. Queryable via /audit, exportable as CSV. SSE stream provides real-time visibility.
A.5.30 ICT Readiness for Business Continuity
Edge gateway degrades to local autonomy if the network drops (firmware fail-safe holds last relay state). Physical wall switch overrides the AI 24/7 (slide 17).
A.8.28 Secure Coding
Parametrized SQLAlchemy ORM (no string SQL). Pydantic validation on every ingress. 33-test pytest suite gates every CI build.

IEC 62443-3-3 — Industrial Automation Security

Architectural compliance
SR 1.1 / 1.2 Identification & Authentication
Each edge node authenticates via deployment-time API key (or MQTT TLS client cert in production transport). Per-room ECOTRUST_ROOM_ID binds firmware to RBAC.
SR 5.1 Network Segmentation
Slide 7's "Strictly Untouched" tier is enforced in code: decision_engine.evaluate() short-circuits for control_tier="untouched". Fire safety, elevators, and main access are physically air-gapped — EcoTrust never writes to those circuits.
SR 7.6 Network and Security Configuration Settings
No BMS write authority required (slide 7). EcoTrust only drives smart relays and FCUs it owns; it advises central HVAC via the notifications endpoint without touching BACnet/Modbus directly. No fault blame, no voided OEM warranty.

Bursa Sustainability Reporting Guide (3rd Edition)

Architectural compliance
GHG Protocol Scope 2 — Location-Based
Calculated continuously: kWh × 0.585 kgCO₂e/kWh (TNB Grid 2024). Endpoint /ghg/scope2; one-click PDF at /export/scope2.pdf.
Audit Trail — Verifiable Evidence
Every kWh has a name (room), a reason (the three-pillar decision log), and verifiable proof (immutable PowerDecision rows + CSV export).
Common Sustainability Matters — Energy
Per-tenant energy attribution via /tenants/attribution open API. Daily kWh budgets per department and per room with breach alerts.
